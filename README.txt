# Инструкция по запуску бота DDNet Art

### 1. Установка зависимостей
Откройте терминал/командную строку в этой папке и выполните:
```bash
pip install -r requirements.txt
```

### 2. Запуск бота
```bash
python bot.py
```

### Структура файлов:
- `bot.py` — основной код бота (Aiogram 3, Telegram Stars, админ-панель, промокоды, проверка подписок).
- `data.json` — база данных промокодов, скидок пользователей, статистики выручки звёзд и добавленных артов.
- `requirements.txt` — список необходимых библиотек (`aiogram>=3.4.0`).
- `media_*.png` — исходные изображения для каталога артов Никиты.
